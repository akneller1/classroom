HOW IT PLAYS
  Teams take turns picking a square. A multiple-choice problem (A-D) appears; the team locks in one answer.
  Correct: the square is theirs. Wrong or time up: the other team may steal it (the wrong choice is crossed out).
  If nobody gets it the square stays open. Three in a row wins. Scores carry across games; the starting team alternates.
  Team names and an optional timer (30/60/90 s) are set on the start screen.

CONTENT
  10 problems per unit, the same verified problems as the Color By Number sheets and detective games. Each has 3 wrong answers
  built from common student errors (sign slips, forgotten flips, mixed-up formulas). Answer order is reshuffled every time.
  Worked solution shown after each square.
CHECKS
  All 480 wrong answers were machine-checked against the answer key (none equivalent to the right answer, none duplicated).
  All 16 games were played in a browser: a steal, a no-winner square, and a full game through a win, with no errors.
