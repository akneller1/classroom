HOW IT WORKS
  Students solve each problem, find the answer in the Color Code box (all answers look alike on purpose), write the problem number on that
  color's blank, then color every region with that number. A wrong answer matches no color, so it self-checks.
  Print at Actual Size / 100% so the picture and boxes fit.

CHECKS DONE
  - Every answer verified with sympy / exact arithmetic, then re-solved blind by independent reviewers (160 of 160 agree).
  - Every printed number was checked by computer to sit inside a region of the right color (all 16 pictures).
  - Every page was checked for text overflow; all PDFs are exactly 2 pages.
  - Pictures and layout were also looked at by eye.
  - Answer formats: students may list roots in either order (for example x = −3, 2) and factors in either order; accept equivalent forms.
