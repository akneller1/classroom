MR. K'S CLASSROOM: DETECTIVE GAMES UPDATE
=========================================
Adds a typed-answer mystery game to all 16 units (129 activities total after this update).

WHAT'S IN THE ZIP
  artifacts/<unit>-<case>/index.html   the game (one self-contained file each, 16 total)
  thumbs/<unit>-<case>.jpg             card preview images (16)
  data.js                              replaces the one on the site (adds 16 cards)

HOW TO UPLOAD (33 files, one batch is fine)
  1. github.com/akneller1/classroom > Add file > Upload files.
  2. Drag in the "artifacts" folder, the "thumbs" folder and data.js together. Commit.

  Color By Number printables). If any of those zips has not been uploaded yet, upload it first, then this one.

HOW A STUDENT PLAYS
  Solve a problem (typed answer) -> unlock a clue -> the suspect/place (or method) it rules out is crossed off the case board.
  After 10 clues exactly one suspect, one place and one method remain; the student makes the accusation.
  Wrong answers just get a message; a hint appears after 2 misses, worked steps after 4. The win screen shows wrong tries and hints used.
  Progress is saved in the student's browser. "Restart case" clears it.
