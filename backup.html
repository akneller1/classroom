Back up saved work

Save a portable JSON copy of work stored by Mr. K's Classroom in this browser. Import it on a second device to restore those saved entries. Files downloaded from individual generators or PDFs are not included.

Important: This tool can only access storage belonging to mrksclassroom.com. Work saved at another domain, in private browsing, or in a different browser profile is not automatically available here. Back up from the original browser and domain.
