ASTEROID BLASTER - SAFE INTEGRATION
1. Extract this ZIP into a temporary folder (not directly over your repository).
2. In a terminal, cd to your local classroom repository folder.
3. Run: python PATH_TO_EXTRACTED_FOLDER/install_asteroid.py
4. Inspect changes in GitHub Desktop, commit and push.
The script preserves the current data.js, inserts game cards once, and copies the HTML and thumbnail.
Coverage follows the supplied game's existing shared course-source question bank adapter; courses without compatible questions may not play. Grade 1-5 and Financial Algebra are not certified by this package.
