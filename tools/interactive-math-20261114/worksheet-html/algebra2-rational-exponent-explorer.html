2Explore use the tool

  1. Set b = 8, m = 2, n = 3. What are the two ways the tool computes the value, and what do they give?

  3. Set b = −8. Try n = 3, then n = 2 (m = 1). What happens and why?
  4. Compare b = 16 with exponents 24 and 12. What do you notice on the graph?
