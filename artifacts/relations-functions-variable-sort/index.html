Input or Output?

Sort each quantity in the situation, then use function notation.

How it works

For each situation, drag every quantity into a box. (You can also tap a quantity and then tap a box.)

  • Independent variable: the input. It changes, and you choose or control it.
  • Dependent variable: the output. It changes because the input changes.
  • Neither: stays the same in this situation, or doesn’t affect the output.

Test your sort with the sentence: “The dependent depends on the independent.” Once it’s right, you’ll evaluate the function.
