Algebra 1 · Relations and Functions · New skills 09 and 10 — teaching notes

Audience: Algebra 1 teacher materials (lesson planner notes, cheat sheet section, vocabulary, activity). Standards: F-IF.C.7b, F-IF.B.4, F-IF.B.5, F-IF.B.6, F-BF.B.3.

Skill 09 · Square-Root and Cube-Root Functions

**Big idea.** y = a√(x − h) + k and y = a∛(x − h) + k are the parent graphs moved by the same rules students already know from linear and absolute value functions: h shifts right, k shifts up, a stretches, and a negative a reflects over the x-axis.
**Key features to name every time:** the starting point (h, k) for a square root (the cube root has a center point (h, k) instead); domain; range; whether the function is increasing or decreasing; and two easy points found by making x − h a perfect square (or a perfect cube).
**Worked example.** f(x) = 2√(x + 3) − 1.
1. Start at (−3, −1), because x + 3 = 0 when x = −3.
2. Choose x-values that make x + 3 = 0, 1, 4, 9: x = −3, −2, 1, 6 → y = −1, 1, 3, 5.
3. Domain x ≥ −3; range y ≥ −1; increasing on its whole domain.
**Common errors (used as MC distractors).** Shifting left for √(x − 3); reading the endpoint as (k, h); giving the domain as x ≥ −h; forgetting that a negative a flips the range (y ≤ k); thinking ∛ of a negative number is undefined.
**Exit ticket.** Give the domain, range and starting point of g(x) = −√(x − 2) + 4, and sketch it from two exact points.

Skill 10 · Piecewise, Step, and Absolute Value Functions

**Big idea.** A piecewise function uses different rules on different parts of the domain. To evaluate it, first decide which condition the input satisfies. At a boundary, the closed dot shows the value; an open dot is not part of the graph. Absolute value functions are a two-piece function with a V shape and vertex (h, k). Step functions are piecewise constant and show up whenever something is charged "per started" unit.
**Worked example (boundary).** f(x) = { x − 3 if x ≤ −1; x if x > −1 }. Then f(−1) = −4, because −1 satisfies x ≤ −1. The second piece would give −1, which is the classic wrong answer.
**Worked example (step).** Parking costs $5 for the first hour or part of an hour, plus $1 per additional hour or part. For 2.5 hours: 1.5 additional hours rounds up to 2, so the cost is 5 + 2(1) = $7.
**Absolute value solving with graphs.** |x − 3| − 1 = 1 has two solutions, x = 1 and x = 5: the V meets the horizontal line y = 1 twice. If the line is below the vertex of an upward V, there are no solutions.
**Common errors.** Using the wrong piece at a boundary; treating an open dot as part of the graph; rounding a step function to the nearest whole number instead of rounding up; writing |x + 2| with vertex (2, k); taking ⌊−3.7⌋ = −3.
**Exit ticket.** Write the piecewise rule for a graph with the ray y = 2x + 1 for x < 0 (open dot at (0, 1)) and the horizontal ray y = 3 for x ≥ 0. Then find f(0).

Vocabulary (for the flashcard and vocabulary builder)

| Term | Student-friendly definition |
|---|---|
| square-root function | A function such as f(x) = √x whose rule takes a square root of the input; its graph starts at an endpoint. |
| cube-root function | A function such as f(x) = ∛x; it is defined for every real number and passes through its center point (h, k). |
| piecewise function | A function defined by different rules on different intervals of its domain. |
| step function | A piecewise function that is constant on each interval, so its graph looks like stairs. |
| greatest integer function | ⌊x⌋, the greatest integer that is less than or equal to x. |
| open dot / closed dot | On a graph, an open dot marks a point that is not included; a closed dot marks a point that is included. |
| vertex (absolute value) | The turning point (h, k) of y = a\|x − h\| + k. |

Classroom activity — "Family Reunion" card sort (20 minutes, pairs)

Print one set per pair. Each family has four cards: an **equation**, a **graph description** (or a graph from the bank images), a **key-features card** (domain, range, starting point or vertex), and a **context** card. Students sort the 24 cards into six families, then write one sentence explaining the clue that separated the two hardest families.
| Family | Equation | Key features | Context |
|---|---|---|---|
| 1 | y = √(x − 2) + 1 | Starts at (2, 1); domain x ≥ 2; range y ≥ 1 | Side length of a square garden whose area is x − 2 square meters, plus a 1 m border |
| 2 | y = −√(x + 1) + 3 | Starts at (−1, 3); domain x ≥ −1; range y ≤ 3 | Water level dropping, fast at first and then slowly |
| 3 | y = ∛(x − 1) | Center (1, 0); domain and range are all real numbers | Side length of a cube with a volume 1 unit less than x |
| 4 | y = \|x + 2\| − 3 | Vertex (−2, −3); range y ≥ −3 | Distance from a mile marker, minus 3 |
| 5 | y = 4 + 2⌈t/15⌉ (t > 0) | Constant on each 15-minute block; jumps of 2 | Bike-share: $4 unlock + $2 per started 15 minutes |
| 6 | y = { 2x + 1, x < 0; 3, x ≥ 0 } | Open dot at (0, 1); closed dot at (0, 3) | Phone plan: pay as you go, then a flat rate |
Answer key: the families are as listed. Differentiation: CP2 pairs get the key-features cards face up; Honors pairs also write the equation for a seventh graph you draw on the board.

Cheat sheet section (drop-in for the unit cheat sheet)

- **Square root:** y = a√(x − h) + k · start (h, k) · domain x ≥ h · range y ≥ k if a > 0, y ≤ k if a < 0.
- **Cube root:** y = a∛(x − h) + k · center (h, k) · domain and range all real numbers.
- **Absolute value:** y = a\|x − h\| + k · vertex (h, k) · opens up if a > 0 · slope of the right side = a.
- **Piecewise:** check the condition first · closed dot = included · open dot = not included.
- **Step:** "per started unit" means round up (ceiling) · ⌊x⌋ rounds down.
