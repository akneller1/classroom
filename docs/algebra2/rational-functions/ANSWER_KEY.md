## Skill 01: Simplifying rational expressions

**a2-rf-s01-cp1-001** (cp1, short-answer)  
Simplify (x² - 5x + 6)/(x² + x - 6) and state the excluded values.  
Answer: **(x - 3)/(x + 3); x ≠ -3, 2**  
Solution: Factor: (x - 2)(x - 3)/((x + 3)(x - 2)). Divide out common factors. Excluded values come from the ORIGINAL denominator: x ≠ -3, 2.

**a2-rf-s01-cp1-002** (cp1, short-answer)
