## Resource connections

All 11 units expose lesson plans, worksheets, assessments, interactive readiness checks, flashcards, Connect 4, Tic-Tac-Toe, Picture Reveal, Showdown, Detective, and Escape Room. Skill selection and exact source difficulty levels are retained. Games use source-marked multiple-choice items; flashcards also use short answers. Original activities, PDFs, thumbnails, and partner checks remain in place.

Native printable defaults pass for maze, color-by-number, partner check, Whodunnit, and stations in all 11 units. Mazes use smaller existing layouts where the finite bank has fewer compatible items. Partner checks use the available source pairs. Capacity varies with selected skills and difficulty; unsupported selections report their limits. No difficulty substitution is permitted for authored banks.

Tarsia cannot fill its minimum template with compatible source items. Error Analysis would require inventing erroneous mathematical work. Those bank-backed options remain disabled; retained original resources are preserved.

Readiness checks automatically grade source-marked choices. Written responses use worked-solution self review, not a symbolic-grading claim. Readiness checks use even source-ID suffixes; formal assessments use odd suffixes, preventing identical source questions from appearing in both. Lesson plans and worksheets can use the full bank.
