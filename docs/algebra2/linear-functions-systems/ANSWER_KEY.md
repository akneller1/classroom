## Skill 01: Linear equations in multiple forms

**a2-ls-s01-cp2-001** (cp2, short-answer)  
Write the equation in slope-intercept form of the line through (1, 3) and (4, 9).  
Answer: **y = 2x + 1**  
Solution: m = (9 - 3)/(4 - 1) = 2. Use b = y - mx with (1, 3): b = 3 - (2)(1) = 1. y = 2x + 1.

**a2-ls-s01-cp2-002** (cp2, short-answer)

Solution: m = (-3 - 5)/(2 - (-2)) = -2. Use b = y - mx with (-2, 5): b = 5 - (-2)(-2) = 1. y = -2x + 1.
