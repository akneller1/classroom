**a2-ft-s01-cp2-001** (cp2, short-answer)  
Let f(x) = 2x² - 3x + 1. Find f(-2).  
Answer: **15**  
Solution: Substitute -2 for every x: f(-2) = 2(-2)² - 3(-2) + 1. (-2)² = 4, so f(-2) = 8 + 6 + 1 = 15.

**a2-ft-s01-cp2-002** (cp2, short-answer)  
Let f(x) = -x² + 4x + 5. Find f(3).  
Answer: **8**  
Solution: Substitute 3 for every x: f(3) = -1(3)² + 4(3) + 5. (3)² = 9, so f(3) = -9 + 12 + 5 = 8.

**a2-ft-s01-honors-001** (honors, short-answer)

**a2-ft-s01-honors-005** (honors, multiple-choice)  
A student says: 'If f(x) = x² + 1, then f(a + b) = f(a) + f(b).' Which value shows the claim is false?  
- ○ a = 2, b = 0: f(2) = 5 and f(2) + f(0) = 5
- ✔ a = 1, b = 1: f(2) = 5 but f(1) + f(1) = 4
- ○ a = 1, b = -1: both sides equal 2
- ○ a = 0, b = 0: both sides equal 1
Answer: **a = 1, b = 1: f(2) = 5 but f(1) + f(1) = 4**  
Solution: Test a = 1, b = 1: f(2) = 4 + 1 = 5. f(1) + f(1) = 2 + 2 = 4, and 5 ≠ 4, so function notation does not distribute. Check the distractors: a = b = 0 gives 1 vs 2, a = 1, b = -1 gives 1 vs 4, a = 2, b = 0 gives 5 vs 6, so none of them is a correct description.
