# Algebra 2 content publication package

Owner requested publication without waiting for a subject-matter review. The 486 generated questions are **unreviewed**.

This package provides file contents to merge into the repository root; it does not itself deploy the site. Its manifest adds three Algebra 2 units to the approved-bank loader, using `approved: true` as a *technical availability flag*, not evidence of editorial review.

**Important:** Importing these files into the repository does not automatically make existing Algebra 2 games and generators use them. Those integrations must separately use the shared question-bank loader and compatible adapters. The current game adapters omit diagram-dependent items and some question formats.

Do not overwrite the repository's manifest if it has gained unrelated entries; merge the three entries instead.
