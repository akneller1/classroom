Relations, Domain & Range · Lesson 3 of 3

Learning objectives

I can identify the domain and range of a relation shown as ordered pairs, tables, and mapping diagrams; explain repeated values; and recognize when a relation is a function.

Language objectives

I can use the terms input, output, domain, range, relation, function, unique and set accurately in a written explanation. I can justify my answer using “The domain consists of … because …” and “This relation is/is not a function because …”.

Do Now · Spiral review (5–7 minutes)

1. Solve: 3(2x − 1) = 21.

2. Solve: −2x + 5 ≤ 13.

3. For the relation { (−2, 3), (0, 5), (4, 3) }, circle the input in each ordered pair and underline the output.

Assess · Exit ticket (4–5 minutes)

1. For { (−4, 2), (0, 2), (3, 9) }, state domain and range.

2. Is { (1, 3), (1, 8), (5, 9) } a function? Justify your answer.

Choose one summary

□ Two-sentence explanation: Compare domain and range using the words input and output.

□ Error analysis: A student claims the range of { (1, 4), (2, 4) } is {4, 4}. Explain and correct.

□ Self-check: “One input can be paired with two different outputs and still be a function.” Agree or disagree, and explain.

Notes: ordered pairs; input/x; output/y; once. Example 1 domain {−3, 1, 4}, range {2, 5, 7}, not a function because input 1 pairs with outputs 5 and 7. Example 2 domain {−2, 0, 3, 5}, range {1, 4, 9}, yes, each input maps to exactly one output. Example 3 domain {−1, 2, 4}, range {5, 8}, arrows as given; each input has exactly one output; different inputs may share an output.

Check: Domain {−1, 2, 6}, range {0, 4, 5}; not a function (−1 has two outputs).

Exit: 1. Domain {−4, 0, 3}, range {2, 9}. 2. No; input 1 has two different outputs. Summary: domain is inputs, range outputs; repeated set elements are written once; claim is false.
